# 📊 E-Commerce Sales Dashboard (Power BI)

An interactive Power BI dashboard analyzing e-commerce sales performance, revenue, key metrics, and customer payment methods.

## 📷 Dashboard Preview
![E-commerce Sales Dashboard](assets/dashboard_overview.png)

## 📌 Key Metrics (KPIs)
- **Total Amount Sold:** 32K
- **Total Quantity Sold:** 306
- **Total Profit:** 5,181
- **Average Order Value (AOV):** 7,897

## 💡 Key Insights & Visualizations
- **Sales by State:** Regional sales distribution highlighting top-performing states like Maharashtra.
- **Quantity by Category:** Product distribution across Clothing, Electronics, and Furniture.
- **Profit Trend:** Monthly profit analysis tracking growth over time.
- **Payment Mode Split:** Percentage breakdown of orders via Cash on Delivery (COD), UPI, Debit/Credit Card, and EMI.
- **Profit by Sub-Category:** Detailed profit margin breakdown by specific product categories (e.g., Printers, Trousers, Accessories, Sarees).

## 🧰 Tools & Technologies Used
- **Power BI Desktop** (Data Visualization & Dashboard Design)
- **DAX** (Data Analysis Expressions for Calculated Measures)
- **Power Query** (Data Cleaning & Transformation)
- **Excel/CSV Data Source**
